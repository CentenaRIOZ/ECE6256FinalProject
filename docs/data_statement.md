# Data Statement

All data in `data/` are synthetic English workplace dialogues made for this project. No data were collected from people, and no real conversations, user logs, or personal records are used.

## Sources

| Set | File | Dialogues | Probes | How the text was made |
|---|---|---:|---:|---|
| Dev | `data/dialogues/dialogues.jsonl` (split `dev`) | 48 | 208 | Templates in `src/generation/content.py`; half of the dialogues paraphrased by a model (below) |
| Test | `data/dialogues/dialogues.jsonl` (split `test`) | 144 | 664 | Same templates as dev, held-out template variants; half paraphrased |
| Fresh | `data/fresh/dialogues_{spread,early,late}.jsonl` | 208 each | 912 each | Templates in `src/generation/content.py`, new timelines, no paraphrase; the three files differ only in where compaction happens |
| Confirm | `data/confirm/dialogues.jsonl` | 208 | 916 | Separate actions, names, and templates in `src/generation/content_newlang.py`, no paraphrase |
| Forged updates | `data/forged/dialogues.jsonl` | 208 | 916 | Confirm with one filler exchange in 200 dialogues replaced by a forged teammate message (`src/generation/forged.py`) |

- **Gold timelines:** `data/timelines/`, `data/fresh/timelines/`, and `data/confirm/timelines/` are generated by `src/generation/build.py` from fixed seeds (commands in the README). Each timeline lists the user's instructions and their changes. Gold labels come from deterministic rules (`src/ledger/reducer.py`), not from annotators.
- **Templates:**
  - The Test and dev templates (`src/generation/content.py`) were written for this project. *The team should state here who wrote them and whether a model helped.*
  - The Confirm templates (`src/generation/content_newlang.py`) and the forged-message templates (`src/generation/forged.py`) were written by Claude (Anthropic) at the team's request, as disclosed in the README.
- **Paraphrases:**
  - Model and selection: in 96 of the 192 Test/dev dialogues, user event turns were paraphrased by Llama-3.1-8B-Instruct at temperature 0.8. A paraphrase was kept only if it passed rule checks on entities, the partial-versus-final distinction, and polarity, and Qwen2.5-7B-Instruct judged it equivalent (`src/generation/paraphrase.py`; prompts in [`prompts.md`](prompts.md)).
  - Audit: `data/paraphrase_audit.md` records an audit of 40 accepted paraphrases. It found 1 label error and 1 borderline case. *The team should state who performed this audit.*
  - Reproducibility: the committed file is the reference, because the paraphrases were sampled.

## Personal data

There is none. All people, companies, amounts, and documents in the dialogues are invented, and any resemblance to real people or organisations is coincidental. Examples include teammates such as "Priya" or "Avery", recipients such as "Nadia Hassan", and vendors such as "Ridgeline Logistics". No human subjects took part, so no IRB review was needed.

The planned human-written test set ([`human_test_set_guide.md`](human_test_set_guide.md)) uses text written only by team members, about invented actions and people.

## Intended use and limitations

- **Intended use:** the data are meant for evaluating how memory methods keep track of standing instructions across context compaction.
- **Language and domain:** English only, office-assistant domain, eight mock tools.
- **Synthetic text:**
  - The dialogues are short (24 to 42 turns) and follow a fixed structure of event turns, acknowledgements, and filler.
  - Decision requests repeat the action's wording, which makes lexical retrieval easier than it would be in real conversations.
  - Results on this data may not transfer to real users.
- **Unsuitable uses:** the data should not be used to train or certify agents for real financial, data-deletion, or communication actions.
